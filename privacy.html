蓝V星图 · 隐私政策

适用于“蓝V星图 · X 中文蓝V榜单”Chrome 浏览器插件 · 最后更新：2026年10月17日

一句话总结

本插件不收集、不上传、不出售任何个人数据。没有账号体系，没有统计分析，没有广告。

插件会访问什么

  • 公开榜单数据：插件每隔一段时间（默认 15 分钟）从 pei-only.github.io/bluev-star 下载公开的榜单 JSON 文件。这是单向下载，不会附带你的任何信息。
  • X（x.com / twitter.com）页面：插件只在你打开的 X 页面上添加榜单卡片、主页徽章和帖子标签，不修改 X 原有内容，不读取你的私信、密码或登录信息，不替你点击、发帖或关注。

保存在你电脑上的数据

  • 插件设置、你收藏的账号、下载的榜单缓存、页面嵌入错误计数，都只保存在你本机浏览器的 chrome.storage.local 中，不会发送到任何服务器。
  • 卸载插件后，这些数据会被浏览器一并删除。

权限说明

  • storage：保存设置、收藏和榜单缓存。
  • alarms：定时刷新榜单。
  • 访问 x.com、twitter.com：在 X 页面上显示榜单。
  • 访问 pei-only.github.io：下载公开榜单数据。

第三方

榜单数据托管在 GitHub Pages，头像图片直接从 X 的图片服务器加载。这些服务的访问日志受其各自隐私政策约束。
